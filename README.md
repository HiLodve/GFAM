# GFAM - 少女全自动 / Girl Fully Automatic

GFAM 是一个面向《少女前线》相关自动化流程的个人项目，采用菜单式命令行入口，整合多个自动化模块、运行状态仪表盘、本地缓存与环境检查脚本。

> v1.0 正式发布版不包含真实 UID、SIGN、Index/index 原始响应、运行缓存、抓包文件或个人账号数据。

## 功能概览

### 主菜单与基础能力

- 服务器选择：SOP、RO635、M4A1、M16、AR-15、EN。
- UID/SIGN 获取：通过统一入口完成登录抓取，功能模块沿用主菜单会话信息。
- Windows 环境检查：检测 Node.js、Python、内置 gflzirc，并给出中文提示。
- 模块化菜单：各模块独立接管命令行，退出后返回 GFAM 主菜单。
- 运行状态仪表盘：主要模块提供固定下方状态面板，显示当前关卡、轮次、仓库、进度、掉落与停止方式。
- 妖精自动：可在主菜单开启妖精自动建造 / 领取 / 强化，并在支持模块中显示妖精自动状态。

### EPA 打捞

- EPA 普通 / 紧急 / 夜战打捞流程。
- 单人打捞模式与满级停机设置。
- 人形与装备掉落统计。
- 夜战专属装备目标统计与自动上锁保护。
- 人形仓库与装备仓库本地估算。
- 仓库不足时的应急拆解与运行结束收尾拆解。

### 13-4

- 13-4 五战练级。
- 13-4 双单人五战四项基础资源打捞。
- 固定双梯队路线与移动梯队显示。
- 运行结束统计四项资源变化。
- 人形掉落拆解与仓库保护。

### 获取训练资料 / 自动训练

- 获取训练资料。
- 自动训练与自动循环入口。
- 本地 Index/cache 优先策略，减少重复请求。
- 自动训练队列按既定规则处理候选对象。

### 零元购

- f2p 零元购。
- f2p_pr 零元购 PR（额外核心）。
- 基于零元购结算掉落的人形仓库估算。
- 本轮掉落拆解与运行结束收尾拆解。

### 教练の妙妙小巧思 / 一键打捞

- 人形一键打捞计划。
- 装备一键打捞计划。
- EPA 夜战专属装备路线规划。
- 目标装备统计、自动上锁保护、装备拆解过滤。
- 装备仓库可安全轮数估算与应急拆解。

### 灰域自动彩蛋

- 灰域彩蛋地图重置与彩蛋任务识别。
- MOVE / BATTLE 彩蛋路线执行。
- BuildingSkillPerformOnDeath 接口支持。
- 正式运行前请求一次 Index/index 写入基准。
- 探查许可证、四项资源、当前灰域积分、当前轮次本地缓存。
- 四项模式下优先消耗探查许可证：1 张探查许可证等价于四项各 10，不足部分补扣四项。
- 当前进度显示：`xxxx/6000（本次运行已完成 x 轮）`。
- 探查许可证 item_id：`10702`。
- 彩蛋积分 item_id：`10736`。
- startMission 短明文响应重试。
- `abortMission` 卡关清理：支持 `-abort` 手动退出当前灰域关卡，并在运行前/异常时尝试清理旧灰域状态。
- 灰域专用固定下方仪表盘与妖精自动状态显示。

## 运行环境

- Windows 10 / Windows 11
- Python 3.11+
- Node.js
- 内置 gflzirc 兼容组件

## 快速启动

双击或在命令行运行：

```bat
run_windows.bat
```

首次运行会进行环境检查。选择服务器后，按菜单提示获取 UID/SIGN，再进入对应功能模块。

## 常用命令

主菜单常用入口：

```text
1 / epa       EPA 打捞
2 / 13-4      13-4 五战练级 / 四项基础资源打捞
3 / pick      获取训练资料 / 自动训练 / 自动循环
4 / f2p       零元购 f2p
5 / f2p_pr    零元购 PR
6 / smart     一键打捞计划 / 装备一键打捞
7 / greyzone  灰域自动彩蛋
fairy         妖精自动建造 / 自动强化开关
auth          重新获取 UID/SIGN
server        切换服务器
0 / exit      退出
```

模块内常见停止命令：

```text
-q  当前 Macro / 当前任务后安全停止
-Q  当前 Micro 后安全停止（部分模块支持）
-E  返回 GFAM 主菜单
```
