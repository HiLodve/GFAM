# v1.1 人形自动制造保护与数量逻辑修正

- 人形制造公式界面中“默认推荐保护”改为“推荐保护”。
- 手枪 Px4风暴(233)、冲锋枪 索米/Suomi(115) 仅作为推荐提示，不再自动加入保护列表。
- 选择 `-n` 时改为“不添加保护并拆解所有产出人形”，不再默认保护该公式所有五星产物。
- 选择 `-y` 时需要手动输入要保护的人形 ID，并根据 `data/gun.json` / `data/gun1.json` 显示名称供确认。
- 新增目标数量输入：
  - 有保护目标时：保护目标累计达到指定数量后停止人形自动制造。
  - 无保护目标时：本次总制造数量达到指定数量后停止人形自动制造。
- 人形自动制造达到目标数量或仓库满且无法安全拆解时，会自动关闭 `doll_enabled`，避免后续后台重启后继续制造。
