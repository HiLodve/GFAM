# GFAM v1.0 正式发布版

GFAM v1.0 为公开发布版，整合当前稳定功能与灰域自动彩蛋热修逻辑。

## 当前功能

- EPA 普通 / 紧急 / 夜战打捞。
- 13-4 五战练级与双单人五战四项基础资源打捞。
- 获取训练资料、自动训练与自动循环。
- f2p / f2p_pr 零元购模块。
- smart 一键打捞计划与装备一键打捞。
- 灰域自动彩蛋模块，包含固定下方仪表盘、运行前一次 Index/index 基准缓存、探查许可证 item_id=10702、彩蛋积分 item_id=10736、票券/四项混合消耗、startMission 短明文重试、abortMission 卡关清理、异常返回 None 与空掉落 [] 语义区分。
- 妖精自动建造 / 领取 / 强化，并在支持模块中显示运行状态。
- 人形/装备仓库本地估算、应急拆解与运行结束收尾拆解。
