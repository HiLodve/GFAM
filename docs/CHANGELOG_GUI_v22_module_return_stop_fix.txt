GFAM GUI v22 - 模块返回与停止按钮整理

- 模块窗口不再显示“停止进程”按钮，避免在子模块窗口里误停止整个 GFAM 后又触发自动重启。
- 模块窗口的“返回主界面”改为模块安全退出流程：
  - A-10、EPA、13-4、pick、f2p、f2p_pr、smart、greyzone：先发送 -q，再发送 -E。
  - factory：发送 -E。
- 返回主界面路径使用“只在 GFAM 仍运行时发送命令”的安全发送方式，不会在进程已经停止时自动重启 GFAM 并把 -E 误发到服务器选择界面。
- 从一个模块切换到另一个模块时，会先执行当前模块的安全退出序列，再进入新模块。
- 保留 v21 日志实时刷新修复、v20 主界面精简、v19 A-10 pending80 拆解修复、v15 干净 mascot/icon UI。
